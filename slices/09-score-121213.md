## Outcome

`score_health` reads `fixtures/FIX-121213.json` and returns the counts for that story. Story health comes from SR-2. Each coverage row comes from SR-1 and SR-3. An empty `mapped_ac_ids` cannot come out as covered, Adequate, or Partial.

The model is not on this path (`docs/orchestration-and-cost.md` §1, node `score_health`).

- A test whose `mapped_ac_ids` is `[]` contributes no covered `ac_id`. The covered set for this fixture is empty. All eight rows have depth `None`, gap `No coverage`, and row status `none`.
- `docs/rag-stand-in.md` holds SR-1, SR-2, and SR-3 and is labeled stand-in. The first paragraph says TBD-HEALTH-1 is still open and that these rules are the sprint stand-in, not the published RAG rule.
- The AC field being empty is a reported fact. It does not change the story health, and it does not hide the eight scenarios.
- Coverage depth is computed from TestCase `type` on mapped tests only. `happy` counts as Positive. The scorer does not map the title prefix `P` / `N` / `A` onto Positive, Negative, or Adhoc. It does not emit the words "partially covered". It does not emit a coverage percentage.
- Story health does not read the coverage rows. Zero bugs is No open bugs, not Red.
- The function returns a JSON object. Suggested keys, used by slices 14, 15, and 21:

```json
{
  "story_id": "121213",
  "title": "SNAP Login Screen",
  "source": "fixture",
  "ac_field": "empty",
  "scenario_count": 8,
  "scenarios": [
    {
      "ac_id": "AC-1",
      "covered": false,
      "mapped_test_ids": [],
      "depth": "None",
      "gap": "No coverage",
      "row_status": "none"
    }
  ],
  "test_count": 18,
  "mapped_count": 0,
  "bug_count": 0,
  "open_bug_count": 0,
  "escaped_bug_count": 0,

  "rule_ids": ["SR-1", "SR-2", "SR-3"],

}
```

`scenarios` has eight entries. `note` copies the story note from the fixture. `bug_count` is the length of `bugs`, including bugs that are not open. `open_bug_count` is the SR-2 subset. On this fixture both are 0.

`coverage_by_type` may stay on the object as a computed count (unset 18 on this fixture). It is not a report section (§10). It must be computed from fields, not typed in as a headline.
