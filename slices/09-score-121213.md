## Outcome

`score_health` reads `fixtures/FIX-121213.json` and returns the counts for that story. The RAG comes from a stand-in rule that is labeled as a stand-in. An empty `mapped_ac_ids` cannot come out as covered.

The model is not on this path (`docs/orchestration-and-cost.md` §1, node `score_health`).

## Done when

`score_health` on the fixture returns:

| Fact | Value |
| --- | --- |
| AC field | empty |
| Description scenarios | 8 |
| Tests | 18 |
| Mapped | 0 |
| Bugs | 0 |
| RAG | Red |
| Rule that set the RAG | SR-2 |

- A test whose `mapped_ac_ids` is `[]` contributes no covered `ac_id`. The covered set for this fixture is empty. Zero of the eight scenarios are covered.
- `docs/rag-stand-in.md` holds the text of SR-1 and SR-2 and is labeled stand-in in the title and the first paragraph. The first paragraph says TBD-HEALTH-1 is still open and that these two rules are the sprint stand-in, not the published RAG rule.
- Stand-in text, so the scorer and the PDF cite the same sentences:
  - **SR-1.** A scenario is covered only when some test lists its `ac_id` in `mapped_ac_ids`. An empty list covers nothing. This is `docs/requirements.md` §6.4 applied to the fixture.
  - **SR-2.** When the story has one or more description scenarios and the mapped count is 0, the overall RAG is Red. SR-2 is why 121213 is Red.
- The AC field being empty is a reported fact. It is not a second RAG and it does not hide the eight scenarios.
- Coverage-by-type counts come from TestCase `type`. Unset types are counted as unset. The scorer does not map the title prefix `P` / `N` / `A` onto happy / negative / edge / security / adhoc.
- The function returns a JSON object. Suggested keys, used by slices 14, 15, and 21:

```json
{
  "story_id": "121213",
  "title": "SNAP Login Screen",
  "source": "fixture",
  "ac_field": "empty",
  "scenario_count": 8,
  "scenarios": [{"ac_id": "AC-1", "covered": false, "mapped_test_ids": []}],
  "test_count": 18,
  "mapped_count": 0,
  "bug_count": 0,
  "bugs": [],
  "coverage_by_type": {},
  "rag": "Red",
  "rule_id": "SR-2",
  "note": ""
}
```

`scenarios` has eight entries. `note` copies the story note from the fixture. `coverage_by_type` may be all zeros plus an `unset` count of 18. It must be computed from fields, not typed in as a headline.
